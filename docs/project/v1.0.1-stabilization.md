## Correções Realizadas

### 1. Catch silenciosos com logging (STB-01)

**Antes:** `.catch(() => {});` — erros de InteractionService, NotificationsService, syncCalendarEvent eram engolidos sem qualquer rastro.

**Depois:** `.catch(e => console.error('[InteractionService]', e.message, e.response?.data));` — erros agora são registrados no console do servidor para debugging.

**Arquivos modificados:**
- `customer.service.ts` — interação de cliente criado
- `appointment.service.ts` — interação de appointment criado, concluído, notificação confirmada
- `sale-payment.service.ts` — interação de venda concluída e pagamento confirmado

### 2. Abertura das interações (corrigido na Sprint CRM)

A Sprint CRM já corrigiu o bug crítico onde `type: 'OTHER'` não existe no Prisma enum `InteractionType`. Todos os services foram alterados para usar `type: 'NOTE'`.
