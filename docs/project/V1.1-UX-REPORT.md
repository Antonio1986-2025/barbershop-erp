## Resumo

| **CSS Variables** | Cores, dark mode, tipografia, bordas, sombras |

| **btn-premium** | Botão padronizado com active scale |
| **skeleton** | Loading shimmer animado |
| **badge** | Status badges com 5 variantes (success/warning/danger/info/muted) + dark mode |
