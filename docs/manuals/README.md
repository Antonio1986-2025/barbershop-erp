## Para cada perfil

### Administrador
Comece pelo **Manual do Administrador** para configurar empresa, unidades, usuários, serviços e produtos. Use o **Guia Rápido** como referência do dia a dia.

### Gerente
Consulte o **Manual do Administrador** para operações de configuração e o **Manual do Usuário** para o fluxo diário. A **FAQ** ajuda com dúvidas frequentes.

### Barbeiro / Recepcionista
Leia o **Manual do Usuário** para aprender o fluxo do dia a dia. O **Guia Rápido** pode ser impresso e deixado no balcão. Consulte a **FAQ** em caso de dúvida.
