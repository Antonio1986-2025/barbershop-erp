# Roadmap — Barbershop ERP v1.1

## v1.1 — Comercial

### MVP Comercial
- [ ] Wizard de primeiro acesso (setup empresa + admin)
- [ ] Cadastro de logo e personalização visual
- [ ] Múltiplas empresas (multi-tenant)
- [ ] Planos e assinaturas

- [ ] Tela de PDV touch-friendly
- [ ] Leitor de código de barras
- [ ] Impressão de cupom fiscal

### Agendamento Online
- [ ] Widget de agendamento para site do cliente
- [ ] Confirmação por WhatsApp
- [ ] Lembretes automáticos (SMS/WhatsApp)

### Financeiro
- [ ] Fluxo de caixa projetado
- [ ] DRE mensal
- [ ] Conciliação bancária

### Mobile
- [ ] PWA (Progressive Web App)
- [ ] Notificações push

### Integrações
